# 2026-06-23 迭代记录：近期市场信号面板组件化

## 本轮目标

在赛道详情和项目工作台都已具备“近期市场信号”能力后，将重复的前端列表、分类筛选、刷新、空状态和来源跳转逻辑抽成共享组件，降低后续两处功能分叉风险。

## 完成事项

- 新增 `frontend/src/components/MarketSignalsPanel.tsx`，统一五类市场信号标签、分类筛选、刷新按钮、收集时间、空状态、来源跳转和无来源 action 渲染。
- 项目工作台 `WorkspacePage` 的 `DealMarketSignalsPanel` 改为数据适配层，复用共享面板，保留项目侧蓝色 hover/选中视觉。
- 赛道详情 `ThesisView` 移除内联市场信号卡片，把 Thesis 信号适配为共享视图项；结构性/热度作为附加 badge，证据跳转仍复用 `evidenceTarget`。
- 顺手去掉两处重复的市场信号分类常量和时间格式化逻辑，后续新增分类或来源展示只需改共享组件。

## 验证命令与结果

- 通过：`cd frontend && npm run build`。
- 通过：`git diff --check`，仅输出既有 Windows 换行提示。

## 发现的问题

- 当前项目工作台与赛道详情仍各自维护“收集状态/自动首次收集”的业务状态，这是合理边界；共享组件只负责展示和交互外壳。
- 赛道详情的无来源信号仍会展示“查看证据”说明，避免把关键词搜索包装成真实来源。

## 下一轮建议

- 给市场信号增加来源质量/相关性评分，优先展示更贴近项目或赛道论点的来源。
- 抽一个 `useAutoMarketSignals` hook，统一项目与赛道的自动首次收集、防抖和错误处理。
- 在后端加入 market signal batch 概念，保留历史收集批次并支持前端查看变化趋势。
